02

The signal — CLM as an alpha model

CLM scores candidate actions against a state instead of generating text. The state is the shared point-in-time fundamentals snapshot; the candidate set is a closed, typed question about the next quarter:

  1. The snapshot renders the state (only data filed by the as-of date — no lookahead).
  2. clm-serve returns appreciate / flat / depreciate probabilities.
  3. CLMAnalyst emits value = p↑ − p↓ ∈ [−1, 1] with the full distribution in metadata.probabilities.
  4. The Kelly blend consumes those probabilities for sizing (other models can too).

Failure contract mirrors the LLM agents: data errors propagate; CLM call/parse failures abstain (metadata.abstained); an unchanged snapshot never pays a second call. Probabilities are relative to the option set.

03

The sizing — Kelly with a 20% buffer

f* = p − (1 − p) / b p = win probability, b = payoff ratio (win per unit risked). f* ≤ 0 means no position — Kelly refuses coin-flips.
deploy = (1 − buffer) × min(Σ f*, gross_target) Kelly fractions set the proportions; the buffer reserves a fraction of the budget. Default buffer 0.2 → full Kelly never deploys more than 80% of the book.

For a directional bet the outcome space is three-way (up / flat / down). A flat outcome is a push — it contributes log(1) = 0 to expected log wealth, so it drops out of the maximization and p is taken conditional on the quarter resolving: p = p↑ / (p↑ + p↓). With b = 1 this reads f* = (p↑ − p↓) / (p↑ + p↓).

The buffer is a budget reserve, not a haircut that scaling can cancel: under the cap the stake is exactly f* × (1 − buffer) per name; when Kelly wants the whole cap, proportions are held on the buffered budget gross_target × (1 − buffer). Either way the remainder sits in cash, and the fund's risk limits remain the master gate afterwards (max_position_pct, max_gross_exposure).

Signals without probabilities fall back to p = (1 + |conviction|) / 2, so any model in the registry can feed the blend. Abstained signals are excluded from both blending and sizing.

Notes

  • Buffer semantics (deliberate): reserve, not haircut — it cannot be cancelled by gross-cap scaling, so the safety margin is visible in every regime.
  • Kelly is not a target: it sizes to the measured edge; with modest edges a Kelly book is simply smaller than a conviction book. Zero-edge names sit in cash instead of taking a position.
  • CLM is a ranker: it only scores the candidates given; its probabilities are relative to that set, and accuracy depends on the state you feed it.
  • Reproducibility: scoring decisions cache to .v2_cache/clm/; a rerun over unchanged snapshots is free and byte-identical.
  • Upstream CLM: model card · code.
